Conceptos clave

Las partes principales de un sistema automatizado trabajan juntas para recibir información, tomar decisiones y ejecutar acciones.

Sensor

Un sensor convierte una condición del entorno en una señal que puede interpretar un controlador. Puede medir temperatura, luz, distancia, humedad, presión, movimiento o la presencia de un objeto.

Actuador

Es el dispositivo que realiza una acción. Puede encender una lámpara, mover un motor, abrir una válvula, activar una alarma o controlar una bomba.

Controlador

Recibe la información, ejecuta un programa y decide qué salida debe activarse. Arduino, los PLC, las computadoras y los microcontroladores son ejemplos de controladores.

Retroalimentación

La retroalimentación permite saber si la acción produjo el resultado esperado. Un termostato mide la temperatura, compara el valor con el objetivo y decide si debe encender o apagar un equipo.

Cómo se relacionan

Un sistema automatizado comienza cuando un sensor detecta una condición. El controlador recibe el dato y lo compara con una regla programada. Si se cumple la condición, activa un actuador. Después, la retroalimentación comprueba el resultado y permite ajustar la operación.

Ejemplo: un sensor de distancia detecta un objeto a menos de 10 centímetros; el controlador interpreta la lectura y enciende una luz de advertencia.

Elementos de un sistema

  • Entrada: información del entorno, de un sensor, botón o usuario.
  • Control: programa que analiza los datos y toma una decisión.
  • Salida: acción realizada por un motor, LED, alarma, válvula o pantalla.
  • Retroalimentación: medición que confirma si el objetivo fue alcanzado.
