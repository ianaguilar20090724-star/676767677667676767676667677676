06.2 / HUMO

Sensor de humo

Detección de humo con lectura analógica, tres niveles visuales y una alarma sonora.

PlataformaArduino UNO
PrácticaHumo + alarma
OrdenCódigo → imagen → video
← Volver al catálogo

1. Código

Arduino · Humo + alarma
int humo;
int rojo = 11;
int amarillo = 12;
int verde = 13;
int alarma = 10;

void setup() {
  Serial.begin(9600);
  pinMode(rojo, OUTPUT);
  pinMode(amarillo, OUTPUT);
  pinMode(verde, OUTPUT);
  pinMode(alarma, OUTPUT);
}

void loop() {
  humo = analogRead(A5);

  if (humo < 930) {
    digitalWrite(verde, HIGH);
    digitalWrite(amarillo, LOW);
    digitalWrite(rojo, LOW);
    noTone(alarma);
    Serial.println("ESTAS FUERA DE PELIGRO");
  }

  if (humo >= 930 && humo <= 960) {
    digitalWrite(verde, LOW);
    digitalWrite(amarillo, HIGH);
    digitalWrite(rojo, LOW);
    noTone(alarma);
    Serial.println("OJO! EL PELIGRO SE ACERCA");
  }

  if (humo > 960) {
    digitalWrite(verde, LOW);
    digitalWrite(amarillo, LOW);
    digitalWrite(rojo, HIGH);
    tone(alarma, 440);
    Serial.println("ESTAS EN PELIGRO");
  }
  delay(500);
}

2. Explicación

El programa lee el valor del sensor en A5. Por debajo de 930 enciende el LED verde; entre 930 y 960 enciende el amarillo; por encima de 960 enciende el rojo y activa el buzzer. También envía el estado al Monitor Serial.
