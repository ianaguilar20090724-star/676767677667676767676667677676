Arduino

Arduino es una plataforma electrónica de código abierto que facilita la creación de prototipos y proyectos de automatización con sensores, programas y actuadores.

PlacasUno · Nano · Mega
EntradasDigitales y analógicas
SalidasLED · motores · relés
← Volver al catálogo

¿Cómo funciona?

La placa recibe señales de sensores por sus entradas, ejecuta un programa y controla salidas. El programa normalmente se desarrolla en Arduino IDE y se transfiere mediante USB.

La función setup() se ejecuta una vez al iniciar la placa, mientras que loop() repite las instrucciones continuamente. Esta estructura permite que Arduino supervise un proceso y reaccione a los cambios del entorno.

Ejemplo: LED intermitente

Este programa configura el pin 13 como salida y enciende y apaga un LED cada segundo. Es uno de los primeros ejercicios para comprobar que la placa, el programa y la conexión funcionan correctamente.

Arduino · ejemplo de código
int led = 13;

void setup() {
  pinMode(led, OUTPUT);
}

void loop() {
  digitalWrite(led, HIGH);
  delay(1000);
  digitalWrite(led, LOW);
  delay(1000);
}

Ejemplo de automatización

Un sensor de humedad se conecta a una entrada analógica. Si la lectura es menor que un límite, Arduino activa un relé para encender una bomba. Cuando la humedad aumenta, el programa apaga la bomba.

Idea central: Arduino conecta la lógica de un programa con el comportamiento de componentes físicos, por eso es útil para aprender automatización mediante prototipos.
